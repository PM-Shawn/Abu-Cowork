---
name: product-listing
description: Write or rewrite an e-commerce product listing (title, selling points, spec table, FAQ) from product specs. Use when the user asks for listing copy, a product title, or a detail page.
---

Produce listing copy in this order: a title under 60 characters, three to five selling points as short lines, a spec table, then an optional FAQ. Use only facts the user supplied; where a fact is missing, leave a clearly marked placeholder such as `[材质]` instead of inventing one. Match the language of the user's specs.
