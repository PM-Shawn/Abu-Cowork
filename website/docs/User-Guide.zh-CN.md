# Abu 使用指南

[English](User-Guide.md) | **中文**

本文按当前 Electron 客户端的真实界面编写。页面名和按钮名用 **粗体** 标出；如果旧截图或旧教程与这里不一致，以应用内实际界面为准。

## 先认识这些名称

| 名称 | 在 Abu 里代表什么 |
|---|---|
| **任务** | 一次从目标到结果的完整工作过程。点击 **新建任务** 开始。 |
| **对话** | 任务的消息与执行记录，完成后会保留在 **最近**。 |
| **工作区** | Abu 本次可以处理文件的文件夹，也是文件访问的主要边界。 |
| **项目** | 绑定一个工作区，并把长期工作的多次对话、默认模型、技能和连接器组织在一起。 |
| **模型** | 对话使用的大模型与服务商配置。入口是 **设置 → 模型**。 |
| **技能** | 针对某类任务沉淀的做事方法。 |
| **代理** | 可分工执行特定任务的角色。 |
| **连接器** | 接入外部工具或服务的扩展，底层使用 MCP 标准。 |
| **能力** | 浏览网页、操作电脑等需要单独检查或授权的系统能力。 |

## 五分钟开始第一个任务

### 1. 安装 Abu

从 [阿布官网首页](https://myabu.cn/) 下载与你的系统和 CPU 架构匹配的安装包。完整步骤见 [安装指南](Installation-Guide.zh-CN.md)。

只运行通过阿布官网首页下载入口获取的安装包。macOS 官方包已经签名并公证；Windows 安装包当前可能触发 SmartScreen，请先核对下载来源和文件名。

### 2. 配置模型

1. 点击左下角头像，打开 **设置**。
2. 进入 **模型**。
3. 点击右上角 **添加**；首次使用时也可以点击 **添加 AI 服务**。
4. 选择供应商和计费方式，填写 API Key。
5. 获取或手动添加模型，执行连接验证后保存。
6. 回到任务页，在输入框附近的模型选择器中选择本次任务要用的模型。

本地模型可选择 Ollama 或 LM Studio。它们不需要云端 API Key，但本地服务必须已经启动，地址和模型 ID 也要与本机服务一致。

### 3. 选择工作位置

- 一次性处理某个文件夹：点击 **新建任务**，在输入框下方选择 **工作区**。
- 长期维护同一件事：创建 **项目**，绑定工作区，并从项目下新建任务。
- 只做不涉及文件的问答：可以不选工作区；当任务首次需要文件时，Abu 会请求你选择目录。

工作区决定 Abu 默认可读写的范围。不要为了省一次确认而选择过大的目录。

### 4. 描述结果，而不是只给动作

推荐把目标、材料、约束和交付物一起写清楚。例如：

> 阅读当前工作区的会议记录，整理一份中文周报。先列出缺失信息，不要编造；最终保存为 `周报.md`，并在回复中总结三个关键风险。

Abu 会按需要读取文件、调用技能或连接器、执行命令，并把结果和仍需确认的事项放回当前任务。

## 界面地图

### 左侧栏

- **新建任务**：开始一个独立任务。
- **工具箱**：管理 **技能、代理、连接器**。
- **自动化**：管理 **定时任务** 和 **监听事件**。
- **最近**：查看、搜索、重命名、导入、导出或删除历史对话。
- **项目**：把同一工作区下的长期任务放在一起。

### 设置

点击左下角头像 → **设置**。当前个人版主要页面如下：

| 页面 | 用途 |
|---|---|
| **偏好** | 外观、语言、关闭窗口行为、行为感知、防止睡眠。 |
| **能力** | 检查阿布内置浏览器、我的 Chrome 和电脑操控是否就绪。 |
| **安全** | 沙箱、网络隔离、默认权限模式、内容安全扫描、授权目录。 |
| **实验** | 按需开启尚在打磨的功能。 |
| **模型** | 配置模型供应商、联网搜索和图片生成后端。 |
| **用量** | 查看请求与 token 用量。 |
| **记忆** | 查看和管理 Abu 记住的个人偏好与项目知识。 |
| **性格** | 调整 Abu 的表达方式和技能提议主动度。 |
| **IM 频道** | 接入飞书、钉钉、企业微信、Slack、微信等消息渠道。 |
| **诊断** | 检查模型、权限、连接器、技能、网络和应用状态。 |
| **反馈 / 版本** | 提交问题、查看版本与更新。 |

实验功能解锁后，设置中可能出现额外页面，例如 **桌宠**。

## 任务执行与安全确认

### 当前任务使用的模型

输入框附近的模型选择器控制当前任务使用哪个模型。模型选择会绑定到这条对话，避免任务进行中因全局设置变化而切换模型；新任务继承项目默认模型或全局默认模型。

### 三档权限模式

全局默认值在 **设置 → 安全 → 默认权限模式**；任务内可用输入框附近的权限模式控件临时切换。

| 模式 | 适合场景 | 行为 |
|---|---|---|
| **请求批准** | 默认使用 | 工作区内常规操作可继续；越界写入、危险命令和敏感电脑操作会询问你。 |
| **替我审批** | 边界清楚、但希望减少打断 | 由 AI 审核部分越界操作；浏览器、通讯、未知应用和高风险结果仍可能询问。 |
| **完全自主** | 可信工作区内的低风险批处理 | 放宽普通操作确认；系统红线、危险结果和明确禁止项仍不会绕过。 |

权限模式不是“关闭安全”。沙箱、敏感路径、危险命令、内容安全和系统权限仍会独立生效。

### 执行计划

当计划包含删除、覆盖、发送、发布、安装等高风险步骤时，Abu 会展示 **执行计划** 并等待你批准。批准计划表示同意按该方案继续，不等于永久授权所有后续结果；真正触发高风险结果时仍可能再次确认。

你可以拒绝计划并说明要修改的步骤。等待批准期间只允许只读操作。

### 交互式问题与停止任务

信息不足时，Abu 会用问题卡让你单选、多选或填写其他答案。回答会直接回到原任务，不需要重新描述上下文。

任务执行中可以点击停止控件。停止会终止当前任务的运行过程，但不会删除已经生成的文件或历史对话。

## 工作区、项目与记忆

### 工作区和项目的区别

- **工作区是文件夹边界**：决定本次任务主要操作哪些文件。
- **项目是长期组织方式**：绑定一个工作区，归拢多条对话，并保存项目默认模型、技能和连接器。

一个项目绑定一个工作区；同一项目下可以创建多条任务。归档或删除项目不会自动删除工作区文件，删除前仍应阅读确认提示。

### 创建项目

1. 在侧边栏的项目区域点击创建入口。
2. 选择 **从零开始**、**从现有对话转化** 或 **使用已有文件夹**。
3. 设置名称、图标和工作区。
4. 可选配置默认模型、技能和连接器。

已为任务选择工作区但尚未创建项目时，界面也可能提示把该工作区升级为项目。

### 三类长期上下文

| 类型 | 谁维护 | 作用范围 |
|---|---|---|
| **个人记忆** | Abu 自动积累，也可手动管理 | 跨项目生效，例如沟通偏好和常用工具。 |
| **项目记忆** | Abu 按工作区积累 | 只作用于对应工作区，例如技术栈、决策和踩坑记录。 |
| **项目规则** | 用户手动编写 | 明确约束 Abu 的做法，优先于自动记忆。 |

个人与项目记忆可在 **设置 → 记忆** 查看。用户级规则位于 `~/.abu/ABU.md`；项目规则位于 `{工作区}/.abu/ABU.md`，大型项目还可拆到 `{工作区}/.abu/rules/*.md`。

项目记忆存放在 `~/.abu/projects/<工作区键>/memory/`，不会默认写进你的 Git 仓库。涉及证件、账号、财务或未公开业务信息时，建议标记为私密记忆，并确保索引描述只写主题、不写具体值。

## 浏览网页

Abu 提供两种不同的浏览方式：

| 能力 | 何时使用 | 登录状态 |
|---|---|---|
| **阿布内置浏览器** | 普通搜索、阅读、点击、填表、截图和内容提取 | 独立会话，不读取你的 Chrome Cookie。 |
| **我的 Chrome** | 你明确要求操作现有标签页，或必须复用 Cookie、扩展和登录状态 | 使用你当前的 Chrome 会话。 |

### 阿布内置浏览器

内置浏览器随 Electron 客户端提供，不需要安装扩展。普通网页任务直接描述即可；网页会在 Abu 的工作区面板中打开，便于你观察和接管。

### 连接我的 Chrome

1. 打开 **设置 → 能力**。
2. 在 **我的 Chrome** 中点击 **连接 Chrome**。
3. 按引导打开扩展管理页和扩展文件夹。
4. 在 Chrome 中开启开发者模式，选择 **加载已解压的扩展程序**，并选中整个 `browser-extension` 文件夹。
5. 返回 Abu，等待连接状态变为 **已就绪**。

该扩展随 Abu 本地提供，不通过 Chrome 应用商店安装。它需要读取和操作网页、管理下载，才能完成你明确交给 Abu 的任务；只应在可信设备上启用。不使用时可在 Abu 中断开，并在 Chrome 中停用或移除扩展。

Abu 只会在你明确要求“使用我的 Chrome”或现有登录状态时选择这项能力。连接断开时，任务会暂停并提示设置，不会静默切换到另一种浏览器。

## 操作电脑

电脑操控默认关闭。开启路径：**设置 → 能力 → 操作电脑**。

macOS 需要两项独立授权：

1. **查看屏幕**：系统设置 → 隐私与安全性 → 屏幕录制与系统音频。
2. **操作界面**：系统设置 → 隐私与安全性 → 辅助功能。

按页面引导打开系统设置，授权后返回 Abu，页面会自动复检。开发版在系统权限列表中可能显示为 Electron，正式安装版显示为 Abu。

电脑操控仍受敏感应用拦截、危险按键、权限模式和高风险结果确认保护。关闭电脑操控后，模型或后台任务不能自行重新开启。

## 工具箱：技能、代理、连接器

### 技能

技能记录一类任务的专业方法。打开 **工具箱 → 技能** 后可以：

- 使用 Abu 创建或手动创建技能；
- 导入包含 `SKILL.md` 的技能文件夹；
- 从注册表查找和安装技能；
- 查看、启用、停用或管理 Abu 沉淀的技能草稿。

技能不是每条任务都要手动选择。已启用且与请求匹配时，Abu 会按技能说明使用它。

### 代理

代理是具备特定职责和工具范围的分工角色。打开 **工具箱 → 代理** 可以创建、导入和管理代理。复杂任务中，主代理可以把边界清楚的子任务交给其他代理处理。

### 连接器

界面统一称为 **连接器**，底层使用 MCP（Model Context Protocol）。打开 **工具箱 → 连接器**，可以添加：

- **本地进程（Stdio）**：填写命令和参数；
- **远程服务（HTTP）**：填写服务器 URL、请求头和超时。

连接器状态显示为已连接、连接中、重连中或未连接。连接失败时，先核对命令、参数、环境变量、URL 和网络，再到 **设置 → 诊断** 复检。

## 自动化与 IM 频道

### 定时任务

进入 **自动化 → 定时任务**，可以新建、暂停、恢复、立即运行或删除任务。创建时设置任务指令、频率、时间、工作区和可选技能，也可以选择把结果推送到 IM 频道。

定时任务只在 Abu 正在运行且电脑未休眠时执行。无人值守任务不会弹出交互式确认；需要批准的危险操作会被跳过并记录，因此不要把必须人工确认的步骤设计成定时任务。

### 监听事件

进入 **自动化 → 监听事件**，可以让 HTTP 请求、文件变化、IM 消息或时间间隔触发任务。每个监听都可以配置过滤条件、防抖、静默时段、工作区和结果推送。

监听事件与定时任务一样由本机 Abu 客户端执行，因此也要求 Abu 正在运行且电脑未休眠；退出应用或电脑休眠期间不会在云端代跑。

HTTP 接收地址默认是本机地址。不要为了外部访问直接暴露到公网；如需跨机器触发，应通过受控网关、内网或带身份验证的转发服务。

### IM 频道

在 **设置 → IM 频道** 添加消息渠道，配置平台凭据、响应方式、能力等级、会话超时和允许用户。不同平台的接收方式和可用能力不同，配置后先检查连接状态，再用一个低风险测试消息验证收发。

凭据只用于你配置的平台连接。不要把 App Secret、Bot Token 或 Webhook 写进对话、项目规则或可共享的技能。

## 模型的辅助能力

### 联网搜索

**设置 → 模型** 会显示 **辅助能力 → 联网搜索**：

- 已启用的模型服务自带搜索能力时，Abu 会标记由该服务内建；
- 不支持内建搜索时，可以展开并配置 Brave、Tavily、Bing 或自建 SearXNG。

搜索是否可用与当前模型服务、API 权限和网络设置有关。需要最新信息时，在任务里明确要求联网搜索并核对来源。

### 图片生成

**设置 → 模型 → 辅助能力 → 图片生成** 使用独立的图片生成后端列表。点击 **添加**，配置供应商、API Key、接口地址和模型 ID，并设置默认后端。

图片生成配置与对话模型分开；能聊天不代表已经具备图片生成能力。

## 诊断、反馈与更新

遇到问题时，先打开 **设置 → 诊断**。诊断按模型、数据与权限、连接器、技能、网络和应用分组检查，可单独重检。

需要求助时：

1. 在 **反馈** 中描述复现步骤、预期结果和实际结果。
2. 只勾选愿意提供的对话和截图。
3. 导出或上传前检查诊断包清单。

Abu 会排除 API Key 和已知密钥，但对话、日志、文件名和截图仍可能包含敏感业务信息，提交前应人工确认。

在 **设置 → 版本** 检查更新。正式版本和安装包以阿布官网首页与应用内更新提示为准。

## 常见问题

### 为什么找不到“AI 服务”页面？

当前页面名是 **模型**。点击左下角头像 → **设置 → 模型**。页面内首次添加时仍可能看到 **添加 AI 服务** 按钮，它指的是新增一个模型服务配置。

### 为什么找不到“MCP 工具”页面？

当前界面统一叫 **连接器**。入口是 **工具箱 → 连接器**；MCP 是连接器使用的底层协议。

### 普通浏览任务需要安装 Chrome 扩展吗？

不需要。普通网页任务使用 **阿布内置浏览器**。只有必须复用现有 Chrome 标签页、Cookie、扩展或登录状态时，才连接 **我的 Chrome**。

### API Key 存在哪里？

API Key 保存在本机的系统级安全存储中，不以明文写入普通应用数据。更换硬件或迁移系统后可能需要重新输入。**设置 → 模型** 底部提供清除所有已保存密钥的入口。

模型请求会把必要的对话内容和 API Key 直接发送给你配置的模型服务商；这不等于所有数据都“完全离线”。请同时阅读所选服务商的隐私政策。

### Abu 会自动上传我的文件吗？

Abu 不会把整个工作区自动上传到 Abu 自有服务器，但完成任务所需的文本、图片或工具结果可能会发送给你配置的模型或外部连接器。诊断与反馈上传需要你主动提交。敏感材料应使用可信模型服务，并限制工作区和连接器范围。

### 定时任务为什么没有执行？

确认 Abu 正在运行、电脑没有休眠、任务处于启用状态、模型可用，并检查 **自动化 → 定时任务 → 执行记录**。需要人工确认的危险步骤会在无人值守任务中被跳过。

### 模型或连接器连接失败怎么办？

先检查 API Key、计费方式、模型 ID、Base URL、命令参数和网络，再运行 **设置 → 诊断**。自定义接口还要确认其 API 格式与配置一致。

### 如何切换语言和主题？

进入 **设置 → 偏好**，选择简体中文、English 或跟随系统，并切换亮色、暗色或跟随系统主题。
